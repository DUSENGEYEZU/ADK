`<div><br class="Apple-interchange-newline">`# Basic ADK Agent Example`<br><br>`## What is an ADK Agent?`<br><br>`The `LlmAgent` (often aliased simply as `Agent`) is a core component in ADK that acts as the "thinking" part of your application. It leverages the power of a Large Language Model (LLM) for:`<br>`- Reasoning`<br>`- Understanding natural language`<br>`- Making decisions`<br>`- Generating responses`<br>`- Interacting with tools`<br><br>`Unlike deterministic workflow agents that follow predefined paths, an `LlmAgent`'s behavior is non-deterministic. It uses the LLM to interpret instructions and context, deciding dynamically how to proceed, which tools to use (if any), or whether to transfer control to another agent.`<br><br>`## Required Agent Structure`<br><br>`For ADK to discover and run your agents properly (especially with `adk web`), your project must follow a specific structure:`<br><br>```<br>parent_folder/<br>    agent_folder/         # This is your agent's package directory<br>        __init__.py       # Must import agent.py<br>        agent.py          # Must define root_agent<br>        .env              # Environment variables<br>```<br><br>`### Essential Components:`<br><br>`1. **`__init__.py`**`<br>`   - Must import the agent module: `from . import agent<br>`   - This makes your agent discoverable by ADK`<br><br>`2. **`agent.py`**`<br>`   - Must define a variable named `root_agent<br>`   - This is the entry point that ADK uses to find your agent`<br><br>`3. **Command Location**`<br>`   - Always run `adk` commands from the parent directory, not from inside the agent directory`<br>`   - Example: Run `adk web` from the parent folder that contains your agent folder`<br><br>`This structure ensures that ADK can automatically discover and load your agent when running commands like `adk web` or `adk run`.`<br><br>`## Key Components`<br><br>`### 1. Identity (`name` and `description`)`<br>`- **name** (Required): A unique string identifier for your agent`<br>`- **description** (Optional, but recommended): A concise summary of the agent's capabilities. Used for other agents to determine if they should route a task to this agent.`<br><br>`### 2. Model (`model`)`<br>`- Specifies which LLM powers the agent (e.g., "gemini-2.0-flash")`<br>`- Affects the agent's capabilities, cost, and performance`<br><br>`### 3. Instructions (`instruction`)`<br>`The most critical parameter for shaping your agent's behavior. It defines:`<br>`- Core task or goal`<br>`- Personality or persona`<br>`- Behavioral constraints`<br>`- How to use available tools`<br>`- Desired output format`<br><br>`### 4. Tools (`tools`)`<br>`Optional capabilities beyond the LLM's built-in knowledge, allowing the agent to:`<br>`- Interact with external systems`<br>`- Perform calculations`<br>`- Fetch real-time data`<br>`- Execute specific actions`<br><br>`## Getting Started`<br><br>`This example uses the same virtual environment created in the root directory. Make sure you have:`<br><br>`1. Activated the virtual environment from the root directory:`<br>```bash<br># macOS/Linux:<br>source ../.venv/bin/activate<br># Windows CMD:<br>..\.venv\Scripts\activate.bat<br># Windows PowerShell:<br>..\.venv\Scripts\Activate.ps1<br>```<br><br>`2. Set up your API key:`<br>`   - Rename `.env.example` to `.env` in the greeting_agent folder`<br>`   - Add your Google API key to the `GOOGLE_API_KEY` variable in the `.env` file`<br><br>`### Use Ollama (local, free)`<br><br>`If you want to test without any cloud quota, you can run a local model with Ollama.`<br><br>`1. Install and start Ollama:`<br>`   - Download from https://ollama.com/download or run `brew install --cask ollama``<br>`   - Open the Ollama app once to start the server`<br><br>`2. Pull a model:`<br>```bash<br>ollama pull llama3.2<br>```<br><br>`3. Set the local endpoint in `.env`:`<br>```bash<br>OLLAMA_API_BASE=http://localhost:11434<br>```<br><br>`4. Update the agent model to use LiteLLM + Ollama:`<br>```python<br>from google.adk.models.lite_llm import LiteLlm<br><br>root_agent = Agent(<br>    model=LiteLlm(model="ollama_chat/llama3.2:latest"),<br>    ...<br>)<br>```<br><br>`## Running the Example`<br><br>`To run this basic agent example, you'll use the ADK CLI tool which provides several ways to interact with your agent:`<br><br>`1. Navigate to the 1-basic-agent directory containing your agent folder.`<br>`2. Start the interactive web UI:`<br>```bash<br>adk web<br>```<br><br>`3. Access the web UI by opening the URL shown in your terminal (typically http://localhost:8000)`<br><br>`4. Select your agent from the dropdown menu in the top-left corner of the UI`<br><br>`5. Start chatting with your agent in the textbox at the bottom of the screen`<br><br>`### Troubleshooting`<br><br>`If your agent doesn't appear in the dropdown menu:`<br>`- Make sure you're running `adk web` from the parent directory (1-basic-agent), not from inside the agent directory`<br>`- Check that your `__init__.py` properly imports the agent module`<br>`- Verify that `agent.py` defines a variable named `root_agent<br>``<br>`### Alternative Run Methods`<br><br>`The ADK CLI tool provides several options:`<br><br>`- **`adk web`**: Launches an interactive web UI for testing your agent with a chat interface`<br>`- **`adk run [agent_name]`**: Runs your agent directly in the terminal`<br>`- **`adk api_server`**: Starts a FastAPI server to test API requests to your agent`<br><br>`### Example Prompts to Try`<br><br>`- "How do you say hello in Spanish?"`<br>`- "What's a formal greeting in Japanese?"`<br>`- "Tell me how to greet someone in French"`<br><br>`You can exit the conversation or stop the server by pressing `Ctrl+C` in your terminal.`<br><br>`This example demonstrates a simple agent that responds to greeting-related queries, showing the fundamentals of agent creation with ADK.`</div>`
